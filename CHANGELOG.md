# 🚀 Обновления Telegram парсера

## 🆕 Версия 2.0 - Глобальный поиск и автоматическое сохранение

### 🌍 Новая функция: Глобальный поиск по всему Telegram

**Что это такое:**
- Поиск постов по всему Telegram, не только в ваших каналах
- Использует встроенный API поиска Telegram
- Находит посты в публичных каналах и группах по всему миру

**Режимы глобального поиска:**

#### 1. 🔍 Поиск по одному ключевому слову
- Введите любое слово для поиска
- Настройте лимит результатов (по умолчанию 50)
- Получите посты со всего Telegram

#### 2. 🎯 Поиск по словам из конфига
- Использует ваши настроенные ключевые слова
- Автоматически ищет по первым 3 словам
- Объединяет результаты и убирает дубликаты

#### 3. 📝 Поиск по новым ключевым словам
- Введите новые слова прямо в интерфейсе
- Временно заменяет настроенные слова
- Идеально для разовых поисков

### 💾 Улучшенное автоматическое сохранение

**Удобные имена файлов:**
```
tg_parser_channels_bitcoin_2024-01-15_14-30-25.txt
tg_parser_global_search_crypto_2024-01-15_14-30-25.txt
tg_parser_global_multi_ethereum_2024-01-15_14-30-25.txt
```

**Автоматическое определение типа поиска:**
- `channels` - поиск по вашим каналам
- `global_search` - глобальный поиск по одному слову
- `global_multi` - глобальный поиск по нескольким словам
- `global_custom` - поиск по пользовательским словам
- `quick_channels` - быстрый режим
