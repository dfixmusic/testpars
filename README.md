# 🚀 Telegram Парсер

Простой и быстрый парсер для поиска постов в Telegram каналах по ключевым словам.

## 🎯 Возможности

- ✅ Поиск постов по ключевым словам в истории каналов
- 🌍 **НОВОЕ!** Глобальный поиск по всему Telegram
- ✅ Мониторинг новых сообщений в реальном времени  
- ✅ Автоматическое сохранение с удобными именами файлов
- ✅ Интерактивный интерфейс с подробными меню
- ✅ Быстрый режим запуска
- ✅ Подробная информация о найденных постах (дата, просмотры, ссылки)

## 📦 Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ваш-репозиторий>
   cd tg-parser
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Получите API данные Telegram:**
   - Перейдите на https://my.telegram.org/
   - Войдите в свой аккаунт
   - Создайте новое приложение
   - Скопируйте `API ID` и `API Hash`

4. **Настройте конфигурацию:**
   ```bash
   cp .env.example .env
   ```
   
   Отредактируйте файл `.env` и укажите:
   ```env
   # Ваши API данные
   API_ID=1234567
   API_HASH=abcdefghijklmnopqrstuvwxyz123456
   PHONE=+1234567890
   
   # Каналы для парсинга (через запятую)
   CHANNELS=@channel1,@channel2,@news_channel
   
   # Ключевые слова для поиска (через запятую)
   KEYWORDS=bitcoin,криптовалюта,блокчейн,новости
   ```

## 📋 Меню программы

1. **🔍 Парсить каналы** - Поиск по истории сообщений в ваших каналах
2. **🌍 Глобальный поиск по всему Telegram** - Поиск по всем публичным каналам
3. **🔄 Мониторинг в реальном времени** - Отслеживание новых постов
4. **📊 Показать последние результаты** - Вывод найденных постов
5. **💾 Сохранить результаты в файл** - Экспорт в текстовый файл
6. **❌ Выход** - Завершение работы

### 🌍 Глобальный поиск включает:
- **🔍 Поиск по одному ключевому слову** - Простой поиск по всему Telegram
- **🎯 Поиск по словам из конфига** - Использует ваши настроенные ключевые слова
- **📝 Ввод новых ключевых слов** - Поиск по произвольным словам
- **💾 Автоматическое сохранение** - Результаты сохраняются автоматически

## ⚙️ Конфигурация

### Файл .env

- `API_ID` - ID приложения Telegram
- `API_HASH` - Hash приложения Telegram  
- `PHONE` - Номер телефона (с кодом страны)
- `CHANNELS` - Список каналов через запятую (можно использовать @username или ID)
- `KEYWORDS` - Ключевые слова для поиска через запятую

### Примеры каналов:
```env
# По username
CHANNELS=@bitcoin_news,@crypto_signals

# По ID (для приватных каналов)
CHANNELS=-1001234567890,-1009876543210

# Смешанный формат
CHANNELS=@public_channel,-1001234567890,@another_channel
```

## 📊 Формат результатов

Для каждого найденного поста выводится:
- 📍 Источник (канал/группа)
- 📅 Дата публикации
- 🔑 Найденные ключевые слова
- 👀 Количество просмотров
- 🔗 Прямая ссылка на пост (если доступна)
- 💬 Текст сообщения

## 💾 Автоматические имена файлов

Результаты автоматически сохраняются с удобными именами:
- `tg_parser_channels_bitcoin_2024-01-15_14-30-25.txt` - поиск по каналам
- `tg_parser_global_search_crypto_2024-01-15_14-30-25.txt` - глобальный поиск
- `tg_parser_global_multi_bitcoin_2024-01-15_14-30-25.txt` - поиск по нескольким словам

## 🔧 Дополнительные возможности

### Настройка лимитов:
При парсинге можно указать количество сообщений для проверки в каждом канале (по умолчанию 100).

### Мониторинг в реальном времени:
Программа может работать в фоновом режиме и уведомлять о новых постах с ключевыми словами.

### Сохранение результатов:
Все найденные посты можно сохранить в текстовый файл с подробной информацией.

## ❗ Важные моменты

1. **Первый запуск**: При первом запуске потребуется ввести код подтверждения из Telegram
2. **Приватные каналы**: Для парсинга приватных каналов ваш аккаунт должен быть их участником
3. **Лимиты API**: Telegram имеет лимиты на количество запросов, программа автоматически делает паузы
4. **Безопасность**: Никогда не передавайте свои API данные третьим лицам

## 🐛 Устранение проблем

### Ошибка авторизации:
- Проверьте правильность API_ID, API_HASH и номера телефона
- Убедитесь, что номер указан с кодом страны (+7, +1, и т.д.)

### Канал не найден:
- Проверьте правильность написания username канала
- Убедитесь, что ваш аккаунт подписан на канал
- Для приватных каналов используйте ID вместо username

### Нет результатов:
- Проверьте правильность ключевых слов
- Увеличьте лимит сообщений для проверки
- Убедитесь, что в каналах есть сообщения с указанными словами
