# ⚡ Быстрый старт Telegram парсера

## 🚀 Запуск за 3 минуты

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка (автоматически)
```bash
python setup.py
```

### 3. Запуск
```bash
python main.py
```

## 📋 Что нужно для настройки:

1. **API данные** (получить на https://my.telegram.org/):
   - API ID
   - API Hash
   - Номер телефона

2. **Каналы для парсинга**:
   - @channel_name для публичных
   - -1001234567890 для приватных

3. **Ключевые слова**:
   - bitcoin, криптовалюта, новости

## 🎯 Примеры команд

```bash
# Обычный режим с меню
python main.py

# Быстрый парсинг
python main.py --quick

# Демонстрация возможностей
python demo.py

# Настройка конфигурации
python setup.py
```

## 📊 Что получите:

- ✅ Поиск постов по ключевым словам в ваших каналах
- 🌍 **НОВОЕ!** Глобальный поиск по всему Telegram
- ✅ Мониторинг в реальном времени
- ✅ Автоматическое сохранение с удобными именами
- ✅ Интерактивные меню для всех режимов поиска
- ✅ Подробная информация о постах
